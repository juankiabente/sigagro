# SIGAgro

**Sistema de Información Geográfica Agropecuaria**

Proyecto de la materia Paradigmas y Lenguajes de Programación III.

## Integrantes
- Juan Carlos Abente (@juankiabente)
- Emilia Auras (@Emiauras)


## Descripción
SIGAgro permite a productores e ingenieros agrónomos registrar sus
establecimientos, delimitar lotes sobre un mapa, definir puntos de
muestreo y llevar el historial de observaciones a campo.

## Estado actual: AE1 — Frontend estático
Maquetado en HTML5 y CSS3, sin frameworks.

| Archivo | Sección |
|---|---|
| `index.html` | Portada |
| `listado_tabla.html` | Listado de lotes en tabla |
| `listado_box.html` | Listado de lotes en tarjetas |
| `producto.html` | Ficha de un lote |
| `comprar.html` | Solicitud de servicio de muestreo |
